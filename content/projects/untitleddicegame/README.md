## Development history

The project page shows the six latest commits from the main branch on GitHub, refreshed hourly. Each entry links to its commit diff, and the full history is linked from the section heading. No handwritten development logs or videos are needed.

A verified snapshot in `commits.ts` keeps the section useful if GitHub is unavailable. The page labels snapshot data with its verification date.

## Adding screenshots

The three screenshots are integrated. To add more later, save files in `public/projects/untitleddicegame/` and add entries to the dice-game `screenshots` array in `app/lib/projects.ts`. Copying extra files alone does not add them to the page.
